# Demo video

The final demo should be a short 3–5 minute walkthrough of the working Gift Planner application.

## Suggested recording order

- **0:00–0:20 — Introduction:** Explain that Gift Planner helps users organize recipients, occasions, gift ideas, and budgets.
- **0:20–0:45 — Register/Login:** Show account creation or login.
- **0:45–1:15 — Dashboard:** Show the dashboard, upcoming occasions, and active plans.
- **1:15–1:50 — Recipients:** Add a recipient, show the list, and open recipient details.
- **1:50–2:20 — Occasions:** Add an occasion and show it on the occasions list/dashboard.
- **2:20–3:00 — Gift plan:** Create a gift plan, set the budget and spending, and show the progress indicator/status.
- **3:00–3:30 — History:** Open history and filter by status.
- **3:30–4:00 — Closing:** Briefly mention Supabase storage/RLS and the main problem the app solves.

## Recording checklist

- Use invented sample data only.
- Turn off notifications before recording.
- Make sure the browser is showing the phone-sized DevicePreview layout.
- Start with a clean account or predictable demo data.
- Do one uninterrupted walkthrough of the main user journey.
- Avoid showing `.env`, Supabase secret keys, or browser developer tools.
- Keep the final video small enough for GitHub.
