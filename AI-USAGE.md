# AI Usage

I used AI as a helper while developing this project. I mostly did the actual work, including setting up the project, testing the app, making changes, and checking if the features worked properly.

AI helped me with some coding problems, explanations, debugging, and suggestions when I was stuck. I also reviewed and tested the changes before using them in my project.

Overall, I would say the work was mostly done by me, with AI being used as a development assistant.

## How I used AI

### Coding help

AI helped me write and improve parts of the Flutter code, especially when I was working on screens, widgets, Supabase services, and database-related code.

I did not simply leave the code without checking it. I ran the application, tested the features, and changed parts when something did not work the way I wanted.

### Debugging

AI helped me understand errors and possible causes. Some examples included:

- Saved records not appearing immediately after saving
- Occasion dates showing the wrong number of days
- Gift-plan status problems
- Budget and spending calculations
- Navigation and screen refresh behavior
- GitHub Pages/Supabase configuration
- RLS and ownership checks

I tested the fixes in the actual application before considering them finished.

### Design and UI

AI also helped suggest UI improvements such as:

- Light and dark mode
- Dashboard layout improvements
- Reusable widgets
- Better spacing and cards
- Theme colors
- Status chips and budget progress

I chose which suggestions to keep based on how I wanted the final app to look.

## What I did myself

I was responsible for the project decisions and final checking. I:

- Decided what features should be included in the MVP
- Tested the app while developing it
- Checked the screens and user flow
- Tested the main CRUD features
- Tested the RLS/security setup
- Checked the live deployment
- Decided which AI suggestions to keep or remove
- Prepared the final project for submission

AI was mainly used when I needed help or got stuck.

## AI gift suggestions

AI gift suggestions were considered as a possible stretch feature, but they are not part of the final MVP.

I decided to keep the current app focused on recipients, occasions, gift plans, budgets, and history.

## Final statement

AI was used as a development assistant, not as a replacement for my own testing and decisions. I reviewed the generated suggestions and made the final decisions about what went into the project.
